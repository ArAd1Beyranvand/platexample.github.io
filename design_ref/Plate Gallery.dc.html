03 — About

One app for every country package.

Each package ships a ~30-line example that draws one plate; the catalogue lives here instead, so no publishable package carries a showcase.

A plate is three independent render-time inputs: a PlateSpec for geometry, a PlateTheme for colour and a PlateCountry for the panel block. Nothing in this app depends on a country package knowing about any other, and no country package depends on this app.
